# Мизан iOS

Нативный шелл того же контракта, что `android/`: WKWebView открывает `https://mizanx.pro`, user-agent содержит `MizanNative/1.0`, bundle id `app.mizanx.mizan`.

IPA из Linux не собирается. Открыть `ios/Mizan.xcodeproj` в Xcode на Mac, выбрать свою команду подписи, Run на симуляторе или устройстве.

Иконка 1024 не вложена: App Store её потребует перед загрузкой.
